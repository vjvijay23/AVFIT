1. Executive Summary & Product Vision

1.1 The Fragmented Fitness Landscape

Contemporary fitness enthusiasts face a pervasive modern dilemma: managing everyday health requires juggling 4 to 6 disparate single-purpose apps. A user typically maintains:

  • A Pedometer / Activity Monitor (e.g. Google Fit, Apple Health, Pacer) for recording daily steps and baseline movement.
  • An Outdoor Tracking Platform (e.g. Strava, Nike Run Club) for recording GPS trail coordinates, kilometer split times, and elevation gains.
  • A Calorie & Macronutrient Tracker (e.g. MyFitnessPal, Cronometer, Lose It!) with cumbersome manual search forms, paywalled barcode scanners, and friction-laden ingredient weighing.
  • A Guided Exercise App (e.g. Nike Training Club, Freeletics) for bodyweight circuits, rep pacing, and interval rest timers.
  • A Social Motivation Network for competing with friends, sharing fitness milestone badges, and celebrating health milestones.

This fragmentation induces app fatigue, conflicting data models, high subscription costs ($80 to $150+ annually across platforms), and ultimately goal abandonment.

1.2 The AVFIT Unified Solution

AVFIT (engineered by Vyalwin) unifies the full spectrum of personal athletic wellness into a single, cohesive, high-performance mobile application. Built on an organic editorial aesthetic (Warm Cream, Deep Forest Green, Terracotta Orange, and Satin Charcoal), AVFIT provides:

⚡ Instant Multimodal AI Vision

Users snap a single photo of any home-cooked or restaurant dish. Google Gemini 1.5 Flash identifies recipes, computes portion weights, and breaks down Calories, Protein, Carbs, Fat, and Dietary Fiber in under 2.8 seconds.

🏃 Outdoor Walking & Running GPS Analyzer

Continuous screen-off GPS breadcrumb logging via an Android Foreground Service, Haversine distance integration, kilometer splits table, and Grade Adjusted Pace (GAP) calculation.

🧬 Scientific Metabolic Engine

Precision Mifflin-St Jeor BMR and TDEE formulas, calculating customized calorie allowances and macronutrient distributions customized to biological sex, height, weight, age, and fitness goals.

🏆 25-Trophy Gamification Room

A multi-tier trophy ecosystem (Bronze, Silver, Gold, Platinum, Diamond) backed by server-side PostgreSQL triggers that guarantee tamper-proof milestone unlocking and community status.

4. Phone Number OTP & Security Engine

4.1 SMS Authentication Architecture

Recognizing that mobile fitness logging requires minimal friction, AVFIT provides native Phone Number OTP Authentication alongside standard email login. The authentication workflow implements defense-in-depth security:

Security & Rate Limiting Guardrails
1. 60-Second Cooldown: Enforces an unskippable 60-second hardware countdown before any resend SMS request can be triggered, preventing SMS toll fraud.
2. Regulatory Carrier Consent: Explicit notice displayed prior to OTP dispatch: "By proceeding, you agree to receive SMS verification codes. Standard carrier rates may apply."
3. Auto-Advancing Cells: Six discrete text inputs that detect single-digit input, advance cursor focus to the next cell immediately, and cleanly handle backspaces.
4. Sandbox Test Bypass: Safe pre-configured developer test numbers (e.g. +1 555-000-1111) with static verification code 123456 for local and automated testing.

4.2 Supabase OTP Implementation Contract

The client communicates with Supabase Auth via src/services/auth.ts: 

// 1. Dispatch OTP SMS Request
export async function sendOtp(phone: string): Promise<{ success: boolean; error?: string }> {
  const formattedPhone = phone.trim();
  const { error } = await supabase.auth.signInWithOtp({
    phone: formattedPhone,
  });
  if (error) return { success: false, error: error.message };
  return { success: true };
}

// 2. Verify 6-Digit Code and Exchange for JWT Session
export async function verifyOtp(
  phone: string, 
  token: string
): Promise<{ session: Session | null; isNewUser: boolean; error?: string }> {
  const { data, error } = await supabase.auth.verifyOtp({
    phone,
    token,
    type: 'sms',
  });
  if (error) return { session: null, isNewUser: false, error: error.message };
  
  // Query profile to determine if onboarding wizard is required
  const { data: profile } = await supabase
    .from('profiles')
    .select('is_onboarded')
    .eq('id', data.user?.id)
    .single();

  return { 
    session: data.session, 
    isNewUser: !profile || !profile.is_onboarded 
  };
}

5. Scientific Metabolic Profiling (Mifflin-St Jeor)

5.1 Clinical Formulation of Energy Expenditure

Rather than relying on arbitrary calorie estimates, AVFIT implements the clinically validated Mifflin-St Jeor Equation, recognized in nutritional science as the gold standard for predicting Basal Metabolic Rate (BMR) with the lowest margin of error (±5%):

Mathematical Formulations

For Males:
$$ ext{BMR} = (10 imes ext{Weight}_{ ext{kg}}) + (6.25 imes ext{Height}_{ ext{cm}}) - (5 imes ext{Age}_{ ext{years}}) + 5$$

For Females:
$$ ext{BMR} = (10 imes ext{Weight}_{ ext{kg}}) + (6.25 imes ext{Height}_{ ext{cm}}) - (5 imes ext{Age}_{ ext{years}}) - 161$$

For Non-Binary / Unspecified:
$$ ext{BMR} = (10 imes ext{Weight}_{ ext{kg}}) + (6.25 imes ext{Height}_{ ext{cm}}) - (5 imes ext{Age}_{ ext{years}}) - 78$$

5.2 Total Daily Energy Expenditure (TDEE) Multipliers

BMR reflects baseline organ metabolic maintenance at absolute rest. Total Daily Energy Expenditure (TDEE) incorporates occupational and structured athletic activity:

Activity Tier Physical Activity Level (PAL) Criteria & Lifestyle Description
Sedentary 1.200 × BMR Desk-bound profession, minimal walking, zero structured training (<3,000 steps/day).
Lightly Active 1.375 × BMR Light daily walking or low-intensity exercise 1–3 days per week (4,000–7,000 steps/day).
Moderately Active 1.550 × BMR Moderate training 3–5 days per week or physically active job (8,000–11,000 steps/day).
Very Active 1.725 × BMR Heavy athletic training 6–7 days per week or endurance runner (12,000+ steps/day).

5.3 Caloric Goal Offsets & Macronutrient Allocation Algorithm

Once TDEE is determined, the algorithm establishes specific calorie targets and computes a clinically balanced macronutrient split:

  • Weight Loss: $ ext{Target} = ext{TDEE} - 500 ext{ kcal}$ (sustainable ~0.5kg/week fat reduction). Enforces an absolute biological floor: $1,500 ext{ kcal}$ for males and $1,200 ext{ kcal}$ for females to prevent metabolic adaptation.
  • Muscle Gain: $ ext{Target} = ext{TDEE} + 350 ext{ kcal}$ (hypertrophic surplus favoring lean tissue accretion over adiposity).
  • Maintenance: $ ext{Target} = ext{TDEE}$.
  • Protein Safeguard: Calibrated at $2.0 ext{g} imes ext{Weight}_{ ext{kg}}$ ($4 ext{ kcal/g}$), preserving lean muscle tissue during caloric restriction.
  • Dietary Fats: Fixed at $25%$ of total daily calories ($9 ext{ kcal/g}$) to maintain essential endocrine hormonal production.
  • Carbohydrates: Remainder of daily calories divided by $4 ext{ kcal/g}$.
  • Hydration Benchmark: $35 ext{ ml} imes ext{Weight}_{ ext{kg}} + 500 ext{ ml}$ activity allowance.

7. Strava-Grade GPS Outdoor Walking Analyzer

7.1 Technical Architecture of Outdoor Tracking

Outdoor walking and running tracking in AVFIT is powered by a dedicated high-precision GPS telemetry engine (src/modules/walking-analyzer/ and src/screens/activity/RecordActivityScreen.tsx). To achieve parity with dedicated athletic trackers like Strava, the engine implements four core capabilities:

🛰️ Screen-Off Foreground Service

Operates an Android Foreground Service with a persistent status bar notification, preventing the OS power manager from sleeping GPS antennas when the phone is locked in the user's pocket.

📐 Haversine Geodesic Distance

Computes exact surface distance between sequential breadcrumb coordinates across Earth's curvature, compensating for spherical geodesics.

🎯 Kalman Noise Filter & Accuracy Gates

Automatically discards spurious GPS readings where horizontal accuracy exceeds 25 meters or calculated instantaneous speed exceeds 30 km/h (teleportation rejection).

📈 Grade Adjusted Pace (GAP) & Splits

Automatically segments walks into 1,000-meter splits with elevation gain/loss calculations, computing Grade Adjusted Pace (GAP) for hilly terrain.

7.2 Geodesic Formulation (Haversine Algorithm)

Given sequential coordinates $P_1(phi_1, lambda_1)$ and $P_2(phi_2, lambda_2)$ where $phi$ represents latitude and $lambda$ represents longitude in radians: 

// Haversine Formulation in TypeScript (src/modules/walking-analyzer/services/HaversineCalculator.ts)
export function calculateHaversineDistance(
  lat1: number, lon1: number, 
  lat2: number, lon2: number
): number {
  const R = 6371000; // Earth mean radius in meters
  const dLat = ((lat2 - lat1) * Math.PI) / 180;
  const dLon = ((lon2 - lon1) * Math.PI) / 180;
  const a =
    Math.sin(dLat / 2) * Math.sin(dLat / 2) +
    Math.cos((lat1 * Math.PI) / 180) *
      Math.cos((lat2 * Math.PI) / 180) *
      Math.sin(dLon / 2) *
      Math.sin(dLon / 2);
  const c = 2 * Math.atan2(Math.sqrt(a), Math.sqrt(1 - a));
  return R * c; // Distance in meters
}

10.3 Server-Side Anti-Cheat Triggers & Idempotency

Trophies in AVFIT cannot be unlocked through client-side API manipulation. PostgreSQL stored procedures (evaluate_user_milestones()) evaluate database mutations upon activity or workout completion:

  • Idempotent Unlocking: Verifies is_unlocked = FALSE prior to timestamp insertion, preventing duplicate point attribution.
  • Human Plausibility Thresholds: Verifies that logged workout duration does not exceed 180 continuous minutes and step cadence does not violate human biomechanical limits.
